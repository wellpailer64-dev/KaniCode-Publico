# KaniCode

Aplicativo Windows para trabalhar com agentes de IA, projetos e plugins.

Site: https://kanicode.pailer.com.br/

## Download

Em Releases, baixe **KaniCode-Setup.exe** para instalar e abrir o aplicativo. O instalador inclui as bibliotecas e os arquivos necessarios. O ZIP completo tambem esta disponivel para uso portatil.

## Conhecimento separado

- O nucleo vanilla traz procedimentos genericos revisados.
- O perfil pessoal, memorias, conversas, credenciais e rotinas ficam na pasta de dados, fora deste repositorio.
- Cada plugin fornece seus procedimentos em seu proprio diretorio e so aparece no catalogo quando instalado.

As contas dos provedores de IA e conexoes externas sao configuradas por cada usuario. Este repositorio publico nao inclui contas, modelos locais, dados de clientes nem o historico do ambiente particular de desenvolvimento.

## Desenvolvimento

Windows, Python 3.13. Dependencias em requirements.txt. Consulte MAPA.md, ROTEIRO.md e CEREBRO.md. Saidas de verificacao ficam em D:/kanivete_testes.
